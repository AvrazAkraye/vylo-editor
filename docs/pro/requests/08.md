# Requests from 08 (Templates B and visuals)

Things this package needs outside its own files. Each says where, what, and why.

1. **`test/motionai.test.mjs`, the plan prompt budget** (`BUDGET = 9500`). With this package's seven templates the plan
   prompt is 10,827 characters; without them 9,046 (the new backdrop and chart words included). The prompt lists every
   template with its fields and hints, so seven templates cannot fit in the 454 characters left, and package 07 adds
   its own. Raise the budget (about 14,000 with both packages) or make `recipeLine` more compact. This is the only
   assertion of `npm test` that fails on this branch.

2. **`motionchatops.ts`, the figure check** ("no figure the model made up"):
   - `sourcedLayer`: a `race` chart keeps earlier values in each datum's label after `|` (`raceSeries` reads them). Only
     `value` is checked today; check every number `raceSeries(label, value).series` returns.
   - `sourcedFields`: a `bar-race` items line holds several numbers (`Apples: 40, 55, 72`); `itemOf` reads only the
     first. Check every number on the line (split as `racerOf` does in `motionrecipes-pro-b.ts`, or with `numbersIn`).
   - `price-card`'s `price` is a `line` field (so the currency and period can be typed); treat it as a figure:
     `numberOf(price up to '/')` must be a number somebody gave, like a `number` field.

3. **`MotionKinds.tsx`, names of the new kinds**: `backdropName` falls through to `Stripes` and `chartName` to `Ring`.
   Add `grain` → `t('Grain')`, `vignette` → `t('Vignette')`, `lightleak` → `t('Light leak')`, `scanlines` →
   `t('Scan lines')`, `halftone` → `t('Halftone')`, and `race` → `t('Race')`. The keys are in the catalogue already.
   The data table edits a race datum's label as text; a short hint under it ("earlier values after a bar: Rome|12 18 25")
   would help, or a small series editor later.

4. **`motionai.ts` (package 10)**: teach the model the race format in the vocabulary line, for example
   `race: label "Name|v1 v2 …" holds the earlier periods, value is the last`, and that the five finishes (`grain`,
   `vignette`, `lightleak`, `scanlines`, `halftone`) go over everything, last in the layers.

5. **Keep when merging**: two compile-forced edits outside this package's files. `motionrecipes-titles.ts` keys `LOOKS`
   by `Ground` (the seven grounds) instead of `Backdrop`; `MotionControls.tsx` has a `race` glyph. Without them `tsc`
   fails once `BACKDROPS`/`CHARTS` grow.

6. **`motioncheck.ts` (package 01)**: a `race` chart is moving through what looks like its hold (between its entrance
   and exit), so a "nothing changes for 3 s" rule should not fire on it; and the finishes are full-frame layers drawn
   over text by design, so "text occluded by a later layer" should skip backdrop layers.

7. **Gallery still (package 06 / `stillTime`)**: `bar-race`'s card is drawn at the starting order. If a template-specific
   hero time is added, the final standing (`raceWindow(chart).to + 0.3`) is the better picture.

8. **`motiontemplates.ts` `WORDS_PER_LINE` (80)**: a racer's line is cut at 80 characters, so ten periods of five-digit
   values fit and twelve periods of seven-digit values do not. Consider a longer line for list fields in data templates.

9. **`docs/MOTION.md`** (wave 2): add the finishes and the race to the file table's description of `motionbackdrop.ts`
   and `motioncharts.ts`; the race's data model is documented at the top of `motioncharts.ts`.

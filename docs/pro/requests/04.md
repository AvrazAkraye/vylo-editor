# Requests from 04 (sound) for files it does not own

1. **`motionedit.ts`, `rebuild()` — keep `sound` (and `scenes`).** A template graphic rebuilt for new words, a new
   shape, language or length comes back from `buildMotion` without the fields it did not build, and the returned
   object copies only `title, fps, backdrop, stage, error, created, updated`. A person who picks Music and then edits
   the title loses the sound without a word. Suggested: add `...(m.sound ? { sound: m.sound } : {})` (and the same
   for `scenes`, package 05's call) to the object `rebuild` returns. A test: `setFields` on a graphic with
   `sound: { mode: 'music', level: 0.6 }` keeps it.
2. **`motionchatops.ts`** — check that applying a model's answer to an existing graphic keeps `sound` unless the
   answer sets it (wave 2 adds `sound.set`: read the value with `readSound`, apply with `withSound`).
3. **`MotionDesign.tsx`** — mount the row after the length and rate rows:
   `<MotionSoundPanel t={t} doc={doc} onChange={(next) => onEdit((m) => withSound(m, next.sound), 'sound')} />`.
4. **`MotionPanel.tsx`** — mount exactly one `<MotionSoundPreview doc={doc} />` where a graphic is open (sidebar and
   full window share it; it is a singleton player and disposes when unmounted).
5. **Export (package 03)** — `renderSoundBed(doc)` returns `null` for no sound and throws when music is asked for
   where there is no Web Audio; report that as `audio: 'dropped'`.
6. **`motionplay.ts`** (optional) — export its `subscribe`, so the preview could follow the clock without a React
   component. Not needed today: `MotionSoundPreview` uses `usePlay`.
7. **Docs** — `docs/MOTION.md`: remove "Sound" from "Not in this version"; add `motionsound.ts`, `motionsfx.ts`,
   `motionsoundplay.ts` and `MotionSoundPanel.tsx` to the file table. SAFETY and THIRD_PARTY_NOTICES: sound is
   synthesised on the device; no sample, no download, no network, no licence.

# Credits: 09 Export and sharing

**No code was copied or translated from HyperFrames** (or from anywhere else). HyperFrames renders
with Chrome and encodes with FFmpeg and has no GIF writer to port; the clone was read for export
presets and nothing in it applied. No file in this package carries an Apache-2.0 header, because none
needs one.

What the GIF writer (`app/src/motiongif.ts`) is built from, all of it public description, written
here from scratch:

- **GIF89a**, the CompuServe specification (1990): header, logical screen descriptor, colour table,
  graphic control extension, image descriptor, LZW with variable-length codes, data sub-blocks.
- **The NETSCAPE2.0 application extension** (the loop count), as every browser reads it.
- **Median cut** colour quantisation (Paul Heckbert, *Color Image Quantization for Frame Buffer
  Display*, 1982): the idea of splitting the colour box with the most error at its median.
- **Ordered dithering** with the Bayer matrix (Bryce Bayer, 1973), built by the usual recursive
  bit interleaving.
- **Floyd–Steinberg** error diffusion (1976): the 7/16, 3/16, 5/16, 1/16 weights.
- **Boyer–Moore majority vote** (1981), weighted by run length, to find each histogram bin's dominant
  exact colour.

The test's GIF decoder (`app/test/pro-export.test.mjs`) is written from the same specification and
shares no code with the writer. ffmpeg and ImageMagick were used only as outside decoders to check
the output, on this machine; neither is called by the app.

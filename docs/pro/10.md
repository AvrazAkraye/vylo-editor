# Work package 10: AI direction — report

Branch `pro-10-direction`. The design and every number's source and choice are in
`docs/pro/direction.md`; this is the manifest.

## What exists

- **`app/src/motiondirection.ts`** (new; was a placeholder). The motion rules as one table and the
  prompt text written from it. No DOM, no imports beyond `motiontypes.ts` (and a type from
  `i18n.ts`), so the check and the templates can import it without a cycle.
- **`app/src/motionai.ts`** (changed).
  - Both system prompts carry the eight numbered rules, between the vocabulary and the reply
    instructions. The planner's are made concrete for the frame and length the person chose; the
    editor's are the general ones.
  - The advice on choosing a palette, a length and a frame moved from the plan system prompt into
    the request, said only for what is the model's to choose.
  - The template list shows `useWhen`, `avoidWhen`, `tags`, `pairsWith` when `META` has them, at
    most `NOTES_MAX` characters a template.
  - The fence: runs of three or more angle brackets in the person's words, the request echoed to the
    editor and the graphic's words are sent as guillemets, so hostile text cannot close `<<<`/`>>>`.
  - The prompt's own free-layer example keeps the rules (first motion 0.2 s in, exit 0.5 s for a
    0.8 s entrance).
  - `findingsPrompt`, and `readEdit` holding figures in a fix request to the request and the graphic.
- **`app/test/pro-direction.test.mjs`**: 84 checks (the table, the rules, the prompts and their
  budgets, the example, template notes, the fence in request, message and graphic, asking with the
  rules, `findingsPrompt` with a 300-case fuzz, and the numbers rule through a fix end to end).

## Deviations from the brief

- `findingsPrompt` is in `motionai.ts`, not `motiondirection.ts`: `readEdit` must recognise its
  messages, and both live with the change flow.
- `readEdit` changed (not asked for): without it, a fix request naming a layer such as
  `stats-number-3` would make "3" a number the person gave.
- The fence hardening (not asked for beyond tests): the old code let `>>>` in a request close the
  block, so the injection tests the brief asked for could not pass without it.
- The choice advice moved into `planUser` to keep the plan prompt inside its budget.
- Two of the digest's numbers were not used: the 80% title-safe box (EBU R 95's 90% instead) and
  the 1.5/4.6/7.3 width ramp (one preset's, not a rule). The digest's "frames 40-55% empty" was not
  found in the skills. Headlines are 2-8 words, not the old prompt's 3-8.
